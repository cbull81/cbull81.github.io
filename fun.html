A fake clickbait wellness blog that shows you exactly what data a website collects about you in real time — screen resolution, timezone, mouse movement, scroll depth, typing cadence, and more. All using standard browser APIs, no special permissions required. Nothing leaves your browser.

Wikipedia Knowledge Graph Generator

A tool for generating knowledge graphs from selected Wikipedia pages based on their proximity via link structure. A network visualization is derived, and page content is analyzed using Claude to evalulate the semantic connections between topics. Additional similar topics missing from the original graph are automatically identified to suggest gaps in the original knowledge mapping.

Wikipedia Math Portal Knowledge Graph

A comprehensive knowledge graph of the Wikipedia Math Portal, generated using the same method as the demo above. The goal is to evaluate how mathematical concepts are interlinked on Wikipedia, and how different frameworks can coincide or diverge. Searching for a specific topic allows the user to view all connected topics and their semantic relationships.
